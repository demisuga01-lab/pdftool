# Contact and Support

## When to use support@wellfriend.online

Use `support@wellfriend.online` for:

- bugs
- processing failures
- upload or download problems
- security reports
- abuse reports

## When to use contact@wellfriend.online

Use `contact@wellfriend.online` for:

- general questions
- API questions
- business and partnerships
- feature suggestions

## What to include in a report

Include as much of the following as you can:

- tool name
- route or page path
- file type
- approximate file size
- exact error text
- job ID if available
- timestamp if available
- what you expected to happen

Failed-job panels include a "Copy report details" button and an "Email support" link to `support@wellfriend.online`. Use those details when reporting a repeated processing failure.

Do not include passwords, private credentials, full backend logs, tracebacks, command lines, or unrelated sensitive content.

## Community help

For updates and community discussion, you can also join the WellFriend Discord server from the main site.
