## File handling

Files are processed temporarily for the selected tool and are not kept as permanent storage.

Download results when they are ready. Results may be cleaned up after the retention window, and Recent Jobs are saved only in your browser.

Most tools use a 25 MB per-file upload limit. File Tools under `/file/*` use a 100 MB per-file limit.

Relevant File Tools and high-risk upload flows can be scanned with ClamAV signature detection. This detects known threats by signature and does not detect every harmful file.
