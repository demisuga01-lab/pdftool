# Image Tools

## Resize images

Change image dimensions for web uploads, documents, or social formats.

Batch Resize supports backend-backed width and height resizing for multiple images or a ZIP of images. Format, fit, quality, and naming behavior use backend defaults in the current batch tool.

## Compress images

Reduce image file size while balancing quality and download weight.

The shared `/compress` workspace includes a Processing Engine selector. Auto is recommended. Manual engines are shown only when they match the detected file type, but success still depends on server tool availability and file compatibility.

## Convert images

Switch between common image formats such as JPG, PNG, WebP, AVIF, TIFF, BMP, or PDF where supported.

## Crop images

Trim away unwanted edges or focus on a specific area.

## Rotate images

Fix sideways images or apply a specific rotation before download.

## Remove background

Create a cutout result for product shots, profile images, or simple graphics. Remove Background uses OpenCV foreground extraction and exports a PNG with transparency. Very fine edges may still need review.

Advanced refinement and background replacement options are planned.

## Watermark images

Apply branding or ownership marks before sharing or publishing.

## Image info

Inspect image dimensions, format, file size, and related details before you process or publish the file.

## Extract text from images

Use OCR on screenshots, scans, and photos that contain readable text. Clean, high-contrast images usually produce better results.

Image OCR links in navigation route through the OCR Tools category. Plain image tools keep the standard 25 MB per-file upload limit and do not show the File Tools virus scanning notice.
