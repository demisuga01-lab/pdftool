# OCR Tools

## Status

Implemented.

## Tools

- OCR Scanned PDF: `/pdf/ocr`
- Make PDF Searchable: `/pdf/ocr-to-searchable`
- Extract Text from Image: `/image/ocr`
- OCR Workspace: `/tools/ocr`

PDF and image OCR links route into the shared OCR workspace where appropriate. OCR jobs are asynchronous and depend on the installed OCR tooling and input quality.
